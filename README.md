## Purpose
Conduct a rigorous, iterative research program into fundamentally **new** computational architectures to advance autonomous software synthesis and intelligent computation.

**Core Rule:** Do not optimize existing transformer/attention/CPU/GPU/OS paradigms. Investigate entirely new execution models, memory organizations, cognitive architectures, verification frameworks, etc.

## Research Workflow (Strict)
Every iteration follows the 10 phases in order:
1. Problem Definition
2. Prior Knowledge Review
3. Design Space Exploration
4. Hypothesis Formation
5. Experimental Design
6. Implementation Planning
7. Implementation
8. Verification
9. Analysis
10. Revision
